How to use it

4 steps · tap to hide›

  1. Set your drawer

    Enter the width and depth of your drawer in inches or mm. If you've measured how deep a row of tools really is, type it under Row depths.

  2. Pick your tools

    Tap each size you own: 10 adds one, tap again for ×2 or ×3, once more to clear. All and None do a whole set. Odd sizes go in the Other boxes, like 21 or 10x2. Sockets have Shallow Mid Deep tabs and wrenches have Regular Stubby Ratcheting tabs. Each one gets its own group.

  3. Read the print sheet

    See how many Mods, labels and magnets you need. What to print lists every part, and Labels shows which sizes need custom labels (orange). Copy list copies it all as text.

  4. Arrange the drawer

    Each size set is a group. Drag a group to move it, even into another drawer. ↻ Rotate turns it front to back. Auto arrange lays everything out again. An orange outline means groups overlap.

Everything you enter is saved in this browser. Sizes for sockets, wrenches and the row depths are estimates, so check your biggest tools by hand. On a phone, open the planner's link in a browser, not a downloaded file. Load example brings back the sample set.

Drawer
