# Mod Planner

A free web tool for planning a tool drawer with the **Mod System**, my 3D-printed modular tool drawer organizers.

Pick the sockets and wrenches you own, enter your drawer size, and the planner shows:

- **What to print:** which Mods you need, how many of each, and a magnet count
- **Labels:** the size label for each slot
- **Drawer layout:** a map of where every group goes in your drawer

**▶ Open the planner:** https://wupinstick-lab.github.io/Mod-Planner/

It runs in your browser. There's nothing to install, and you don't need an account.

---

## How to use it

1. **Enter your drawer.** Set its inside width and depth, in mm or inches.
2. **Pick your tools.** Tap a size chip to add it. Tap again for 2 or 3 of the same size. Each drive size has separate Metric and SAE grids, plus Shallow, Mid and Deep tabs. Wrenches have Regular, Stubby and Ratcheting tabs.
3. **Arrange the layout.** Each size set is its own block, and SAE blocks are hatched.
   - Drag blocks to move them, and tap **Rotate** to turn one.
   - Use **Auto arrange** to start over.
   - Use **Add drawer** if everything won't fit in one drawer.
   - Blocks outlined in orange overlap.
4. **Print.** Use the print list to download each Mod from MakerWorld.

Your selections are saved in your browser, so the page remembers them the next time you open it.

> **Tip:** On a phone, open the link in your browser. If you download the file and open it from the Files app, the buttons won't work, because the Files preview doesn't run the page's scripts.
